# Politique de sécurité

## Signaler une vulnérabilité

Merci de **ne pas créer d'issue publique** pour signaler un problème de sécurité.

Envoyez votre signalement de manière privée à : **[elieadiko5@gmail.com](mailto:elieadiko5@gmail.com)**

Merci d'indiquer :

* le problème découvert ;
* les étapes permettant de le reproduire ;
* la version concernée.

Je répondrai dans un délai de **7 jours**.

## Versions prises en charge

Seule la **dernière version 0.1.0** reçoit des correctifs de sécurité.
